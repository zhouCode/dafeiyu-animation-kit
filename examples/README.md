# 接到哪里

## 网页 / WebView

根目录示例完全静态，`src/atlas-player.js` 不依赖框架。可将 canvas 放进应用助手、浏览器侧栏或网页挂件。宿主负责布局、点击穿透和语音事件映射。把倾听、思考、说话事件映射到同名动作即可，素材没有逐音素口型数据。

## 桌宠

可以把网页示例装进 Electron、Tauri 或其他透明窗口壳，或在原生绘图组件中使用 PNG 序列。窗口置顶、透明区域点击穿透、多显示器坐标、系统托盘和自动启动均属于宿主功能；**本仓库当前不包含实现这些功能的可安装桌宠程序**。

拎起的 pointer capture 逻辑可以保持在画布内；跨窗口移动时由宿主移动窗口并把速度传给角色摆动。角色走到屏外后，窗口应留出探头的可点击区域，避免直接移到不可交互的位置。

## 小屏幕 / ESP32 等

Release 的 compact 包为独立 WSP2 精灵，不包含固件、分区表、网络配置或设备身份。文件可放入文件系统、外部存储或自行设计的资源分区，使用 zlib 解压、索引调色板和 alpha 合成。

compact 包经过额外裁剪、缩放和调色板压缩，尺寸与网页图集不同，必须使用该包自己的 manifest，不可套用网页 anchor。格式见 [WSP2](../docs/wsp2.md)。不同板卡的显示驱动、PSRAM 和刷新预算需自行验证；此仓库不会自动识别或烧录硬件。
