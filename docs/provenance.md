# 来源与制作记录

版本：0.1.0，整理日期：2026-11-02。

- 参考作品与版权状态详见 [ASSET-NOTICE.md](../ASSET-NOTICE.md)，不重新分发原始参考图。
- 制作采用 AI 关键姿势编辑、MiniMax-H3 本地视频生成、抽帧、透明化和固定配准。项目来源：[MiniMax-H3](https://github.com/MiniMax-AI/MiniMax-H3)、[ComfyUI](https://github.com/comfyanonymous/ComfyUI)。本仓库不分发其模型权重或完整推理环境，也不把模型许可当作角色美术授权。
- 动作制作时间主要为 2026-10-25 至 2026-10-26，当前素材选自已经用于互动预览和设备播放的版本。
- 快速缩回采用独立片段，左侧为19帧、右侧为23帧。好奇使用修订后的动作。拎腰保留围裙位置修订与1.28整体显示比例。
- 本版只包含当前有效31段；底部探头、底部缩回、底部跳回和早期废弃实验没有公开打包。
- 跳回、下落等运动由播放器位移组合实现。没有新增视频模型输出，也没有为了凑30fps重复填帧。
- `assets/manifest.json` 保存当前图集 SHA-256，PNG/WSP2 发布包另有总包校验文件。

代码工具为独立抽取/重写的通用实现。没有复制整套设备固件、语音后端、模型配置、运行日志或私人设备备份。示例的场景与状态机用于说明接入方式；不意味着所有平台都已实机验证。
